# AMP Стройплощадка — тренажёр системного дизайна

Собираешь архитектуру под кейс, пускаешь нагрузку и видишь, где она ломается.

**Открыть:** https://andreypol1991.github.io/system-design-trainer/

Что внутри:
- уровни от одного сервера до микросервисов, событий, CQRS и AI-компонентов;
- «Провалиться внутрь» — живая механика балансировщика, сервиса (потоки, ядра, пул, слои кода), реляционной БД, кэша, брокера и обработчиков;
- архитектура и паттерны прямо на схеме: линзы, подсказки «чего не хватает», применение в один клик;
- «Ландшафт» — CI/CD и GitOps, Kubernetes, логи, метрики, трейсы, алерты, данные и аналитика, метрики DORA и сценарии инцидентов;
- режим собеседования, практикум паттернов, лаборатории.

Статический сайт без сборки: `index.html` + `js/`.
